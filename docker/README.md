# Running SigNoz via Foundry (required for submission)

The hackathon requires the repo to include `casting.yaml` + `casting.yaml.lock`,
and judges re-run **Foundry** against them to reproduce your SigNoz deploy. So we
install SigNoz with `foundryctl`, not raw docker-compose.

## 1. Install foundryctl
```bash
curl -fsSL https://signoz.io/foundry.sh | bash
foundryctl --help
```

## 2. Get a casting.yaml
A minimal one is committed at the repo root (`../casting.yaml`). To generate a
full, version-matched one instead:
```bash
foundryctl gen examples        # writes working casting files for each mode
```
Prefer the generated Docker/compose casting if it differs from the minimal one.

## 3. Deploy (this writes casting.yaml.lock)
```bash
foundryctl cast -f ../casting.yaml
```
`cast` validates tooling, forges the deployment files, and brings SigNoz up in one
step. It writes **`casting.yaml.lock`** (resolved config + checksums) — **commit
that file** next to `casting.yaml`. Foundry also installs the SigNoz **MCP
server** in the same step (we use the REST API at runtime, but MCP being present
is fine).

- UI: **http://localhost:8080** (older builds: `:3301`)
- OTLP ingest (our agent exports here): gRPC `:4317`, HTTP `:4318`

## 4. Create an API key (dashboards + query API)
SigNoz UI → **Settings → Service Accounts** → create account → **Keys** →
generate. Put it in `.env` as `SIGNOZ_API_KEY`.

> Capability check: confirm your version exposes Service Accounts / API keys and
> `POST /api/v5/query_range`. If not, everything still works via the UI: import
> `../track03_cost_per_outcome/dashboards/` from `panels.md` and create the alert
> manually.

## 5. Point the project at it
```bash
cp ../.env.example ../.env    # set LLM_PROVIDER=ollama, models, SIGNOZ_* 
```

## Endpoints this project uses
| Purpose             | Endpoint                                   |
|---------------------|--------------------------------------------|
| Trace/metric export | OTLP gRPC `:4317`                          |
| Query data          | `POST {SIGNOZ_API_URL}/api/v5/query_range` |
| Create dashboards   | `POST {SIGNOZ_API_URL}/api/v2/dashboards`  |
| Create alerts       | `POST {SIGNOZ_API_URL}/api/v1/rules`       |

Auth header on all REST calls: `SIGNOZ-API-KEY: <key>`.

## Files to commit for judges
- `casting.yaml`  (declarative deploy)
- `casting.yaml.lock`  (generated by `foundryctl cast` — real checksums)
